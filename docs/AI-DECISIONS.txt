# Architectural Decisions

- Target framework remains .NET Framework 4.7.2 to match RimWorld's modding
  sandbox.
- Solution intentionally links metadata XML and documentation assets for
  visibility in Visual Studio.
- Added an xUnit-based regression project that validates XML defs without
  needing RimWorld binaries so Codex can run automated checks in CI-friendly
  environments.
2024-07-29 R. Talon: Rebuilt the Random Replicator comp and self-destruct
logic to replace truncated placeholders. Added an internal ThingOwner-backed
queue, power loss letters, weighted food selection, and self-destruct
 countdown telemetry while preserving the mod's intent. Introduced a
 netstandard core library so helper logic remains unit-testable from
 RandomReplicator.Tests.
2024-08-18 R. Talon: Raised the repository standard to require XML
documentation for every function, codified in AGENTS.md, and updated the
Random Replicator comp plus unit tests to comply.
2025-10-12 R. Talon: Surveyed Harmony and HugsLib guidance on mod
  compatibility. Confirmed the project already targets the recommended
  .NET 4.7.2 toolchain, avoids bundling third-party libraries, and
  therefore needs no code changes after this audit.
