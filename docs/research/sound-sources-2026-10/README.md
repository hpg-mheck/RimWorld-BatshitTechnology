# Sound Sources Research Notes (2026-10-15)

The raw notes behind `docs/SOUND-SOURCES.md`, from four read-only
research passes by Claude agents for Phase 5000, slice 1000. Each pass
read the brief (`brief.md`) and wrote one report:

- `music-services.md`: hosted AI music services, their prices, licences,
  controls and Content ID risk.
- `sfx-sources.md`: AI sound-effect services, sound libraries and their
  licences, and an effect-by-effect recommendation.
- `local-and-composed.md`: open models run locally, music composed as
  code and rendered with free instruments, and a listening-trial plan.
- `licensing.md`: copyright in AI audio, Steam's and Ludeon's terms,
  community reception, YouTube Content ID and the label settlements.

Prices and terms change; each source carries the date it was read. The
passes ran out of web searches near their ends, so some late facts rest
on secondary sources and are marked "secondary" or "unverified". The
facts that decide the choice were rechecked against primary pages (see
`docs/SOUND-SOURCES.md`, "Sources"). These notes are a record; they are
not maintained.
